# 贡献文档、示例与问题反馈


## 欢迎的贡献

使用步骤更清晰的改写、失效公开链接的修复、平台名称更正、无障碍与翻译改进、虚构示例和离线检索体验的改善。

## 文档贡献流程

1. 在 `docs/wiki/` 找到对应页面；平台页面以 `Platform-` 开头。
2. 使用真实可核实的公开信息修改步骤，说明适用入口和限制。
3. 检查相对链接和代码块，运行公开文件检查。
4. 提交 PR，说明修改原因和验证方法。
5. 维护者审阅后，将副本批量同步到 GitHub Wiki。

## 新平台需求

在 Issue 中提供平台名称、公开官网、课程类型以及你需要完成的任务。请使用脱敏说明，不要提供账号、会话文件、课程样本或专有适配器代码。提交需求不表示平台已经支持。

## 报告使用问题

提供版本、平台入口、复现步骤、期望结果和脱敏错误信息。属于安全或隐私的问题走[安全反馈渠道](../../SECURITY.md)。

公开源码贡献要求见 [CONTRIBUTING](../../CONTRIBUTING.md)。修改需要保持“公开示例”和“官方客户端”的边界清晰。
