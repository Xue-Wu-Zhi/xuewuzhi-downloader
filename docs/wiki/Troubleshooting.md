# 排错指南


先确认客户端版本，再区分问题发生在“登录”“列表”“下载”“转换”还是“播放”阶段。这样反馈更容易定位。

| 现象 | 优先检查 | 下一步 |
| --- | --- | --- |
| 发布包无法打开 | 下载是否完成、哈希是否一致、系统是否为 Windows | 看[安装说明](Installation.md) |
| 登录后返回首页 | 原平台能否登录、入口是否匹配、是否完成验证 | 看[登录指南](Login-and-Accounts.md) |
| 课程列表为空 | 账号、PC / App 产品线、班级或企业、访问有效期 | 看[课程选择](Courses-and-Selection.md) |
| 找不到部分课程 | 课程期次、当前加载范围、原平台开放状态 | 记录预期与实际数量 |
| 有视频没有课件 | 是否选择资料、原课程是否真的有附件 | 看[课件说明](Courseware.md) |
| 出现 401 / 403 | 登录或链接可能失效，也可能权限不足 | 重新核对原平台权限，再按提示登录 |
| 多次出现 429 | 服务端正在限制请求频率 | 停止重复尝试，按提示等待后再试 |
| 下载进度完成但仍运行 | 是否正在合并、转换或处理板书 | 等待最终结果，观察处理进度 |
| 成片缺背景或板书 | 原内容是否完整、依赖资源是否可访问 | 看[板书说明](Board-and-Conversion.md) |
| 媒体不能播放 | 文件是否完整、任务是否结束、播放器兼容性 | 抽查同课程其他课节 |
| 磁盘写入失败 | 空间、目录权限、外置盘连接 | 换到可写目录后重试 |
| 万能模式没有资源 | 是否实际播放了具体内容 | 看[万能模式](Universal-Mode.md) |

## 哪些内容不要公开

手机号、邮箱、验证码、登录二维码、Cookie、Token、完整鉴权链接、课程媒体及订单信息。截图可只保留出错区域。安全或隐私问题请通过[安全反馈说明](../../SECURITY.md)中的官方联系入口处理。

本仓库的离线示例和官方客户端是两种不同组件。反馈前说明问题发生在哪里，避免把骨架没有下载引擎当作运行故障。
