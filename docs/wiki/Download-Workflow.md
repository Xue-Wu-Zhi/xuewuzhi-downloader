# 一次课程任务的完整流程


一次任务通常经历入口选择、账号验证、课程选择、资源处理和结果检查。不同平台可能合并其中一些步骤。

## 1. 确定入口

同一品牌可能有 PC、App、企业版或独立产品入口。使用与实际上课方式一致的入口，比只按品牌名猜测更可靠。[平台索引](Platforms.md)列出了当前公开指南。

## 2. 确认课程权限

登录后应能在原平台中打开对应课程。下载器自己的账号或会员状态不能替代课程平台的购买、报名、班级或有效期要求。

## 3. 核对课程与章节

检查课程名称、期次、班级和章节；若界面提供资源类型选择，选择所需视频、音频或资料。先检查一个课节，避免把“目录已加载”误认为“所有资源都已开放”。

## 4. 选择输出目录

选择有写入权限且空间足够的位置。下载过程中尽量不要重命名任务目录、移动临时文件或同时用另一程序修改输出内容。

## 5. 等待所有处理阶段结束

![课程下载、合并转换与完成检查的三个阶段](../../assets/guides/download-finish.png)

*通用操作示意，使用虚构数据；不是客户端截图，具体界面以当前版本为准。* [查看大图](../../assets/guides/download-finish.png)

| 阶段 | 你可能看到的现象 | 如何判断 |
| --- | --- | --- |
| 列表与资源准备 | 章节数、资源数逐渐出现 | 等待列表加载完再核对 |
| 下载 | 文件大小增长、显示进度 | 关注具体任务错误提示 |
| 合并或转换 | 下载进度完成但程序仍在工作 | 继续等待最终结果 |
| 板书处理 | CPU 占用较高、耗时超过下载 | 检查处理是否仍有进展 |
| 完成 | 输出文件与最终提示出现 | 打开抽样文件检查 |

## 6. 验证与补全

抽查视频开头、中间和结尾，并检查课件能否打开。遇到缺失内容，先将输出与选择范围、原平台开放状态对照，再重新获取有效链接或提交问题。重试是否能接续已有文件取决于具体任务类型，不要把重新开始当作所有平台都支持断点续传。
