# 常见问题


## 学无止下载器是什么？

学无止下载器是 Windows 网课视频下载与课件整理工具，用于保存有权访问的视频、回放、音频和资料，并处理支持格式的板书与三分屏课程。[功能与产品信息](Product-Overview.md)

## 支持哪些平台？

[支持平台总表](Platforms.md)逐项列出平台名、使用入口和视频下载教程。目录包含 151 项平台入口及 5 项工具；同一品牌可能分多种入口，实际可用内容以课程为准。

## 这是完整开源的下载器吗？

本仓库开放文档、公开平台目录和独立编写的离线骨架。官方客户端的核心下载引擎、账号系统与平台适配实现不在仓库中。需要实际下载功能请使用 Releases 中的客户端。

## 下载 Source code 后为什么不能下载课程？

Source code 是 GitHub 自动生成的当前仓库源码包，只包含公开骨架。Windows 用户应下载 Release 中的 `.exe` 文件。

## 支持 macOS 或 Linux 吗？

当前官方发布包面向 Windows。Python 骨架可在满足版本要求的环境运行，但这不代表官方客户端支持这些系统。

## 是否免费？开源后会员和试用规则会变化吗？

MIT 许可适用于本仓库的公开内容。客户端的试用、会员、学豆或服务价格以官方当时展示的规则为准；开源骨架的许可不改变客户端服务规则。本文不承诺永久免费或不限量下载。

## 是否能下载没有购买或已经过期的课程？

需要具备原平台相应访问与保存权限。付费、报名、有效期、下架状态等由课程平台决定，下载器不能为账号增加课程权限。

## 为什么平台在目录里，某门课仍失败？

目录表示公开教程的收录情况，不是逐门课程的兼容保证。不同课程类型、平台更新、账号状态和资源开放情况都会影响结果。

## 所有平台都能批量下载吗？

不同入口提供不同选择方式。只在当前入口明确提供批量链接、多选或相应选项时使用，不要把一处入口的能力套用到其他平台。

## 三分屏课程为什么比普通视频耗时长？

视频、音频、板书和背景可能需要额外处理。下载速度不代表后续转换速度，先等待客户端给出最终结果。

## 万能下载模式是不是支持所有网站？

不是。它依赖实际识别到的资源及当前支持的处理方式，详情见[万能模式](Universal-Mode.md)。

## 可以把下载的课程分享给别人吗？

软件许可不包含课程版权授权。按课程提供方授予的权限使用，不要未经授权转售或传播课程内容。

## 如何申请新平台或完善教程？

在 Issue 中提供平台名称、公开官网和使用场景，不要附真实账号或核心实现。文档修正可直接提交 PR。
