# 视频、音频与直播回放


## 可以处理哪些内容

客户端可处理支持入口中实际返回的课程视频、音频和已开放回放。平台没有提供的清晰度、尚未生成的回放或无权访问的内容，不会因为选择了“全部”而自动出现。

## 清晰度与格式

![视频音频下载后等待合并并检查播放结果](../../assets/guides/download-finish.png)

*通用操作示意，使用虚构数据；不是客户端截图，具体界面以当前版本为准。* [查看大图](../../assets/guides/download-finish.png)

如果入口提供清晰度选项，按当前界面选择。部分课程只开放一种质量。文件扩展名与实际输出由源媒体和处理方式决定；不要通过手动改后缀来修复播放问题。

| 内容 | 检查重点 |
| --- | --- |
| 普通录播 | 开头、中段和结尾能否播放，音画是否同步 |
| 直播回放 | 原平台是否已生成回放，是否开放给当前账号 |
| 音频课程 | 播放时长、文件是否完整、是否选到了音频类型 |
| 分段媒体或 M3U8 | 下载完成后是否仍有合并阶段 |
| 板书与三分屏 | 是否需要额外处理才得到完整成片 |

## 下载完成仍然不能播放

先等客户端报告最终处理完成。检查文件大小、播放器是否支持该格式，并抽查其他课节。只有某个课节有问题时，保留该课节的脱敏描述；整门课程都有问题时，优先检查所用入口与当前版本。

媒体地址可能带有效期。旧链接失效后，应从有权限的原平台重新获取，避免反复重试同一个已失效链接。[直链指南](Platform-media_links.md)

三分屏和本地转换的特殊情况见[板书与转换](Board-and-Conversion.md)。
