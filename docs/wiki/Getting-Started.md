# 从这里开始


目标是先完成一门课中一个章节的保存，确认入口、账号和输出都正确，再扩大选择范围。

## 准备好三样东西

- 一台 Windows 电脑，以及足够存放课程和临时处理文件的磁盘空间。
- 你实际用于上课的账号，并确认课程在原平台可以打开。
- [最新官方客户端](https://github.com/Xue-Wu-Zhi/xuewuzhi-downloader/releases/latest)。不要把 Source code 下载包当作安装程序。

## 第一次使用

![网课视频下载入门：平台列表与课程链接两种入口](../../assets/guides/choose-entry.png)

*通用操作示意，使用虚构数据；不是客户端截图，具体界面以当前版本为准。* [查看大图](../../assets/guides/choose-entry.png)

1. 下载并运行 `xuewuzhi-downloader-2.19.56-windows.exe`；如需核对文件，按[安装与校验](Installation.md)操作。
2. 启动客户端，在首页输入 `A` 打开平台列表，选择你上课时使用的平台。具体菜单名称见[平台索引](Platforms.md)。
3. 如果该平台使用课程链接入口，复制具体课程页或学习页地址，按入口提示粘贴。平台首页一般不等于课程链接。
4. 在客户端引导的登录窗口登录自己的课程账号，完成原平台要求的验证。
5. 核对课程名称、开课期次和章节，先选择一个短课节及一份可用课件。
6. 设置保存目录并开始任务。出现“合并”“转换”“板书处理”时继续等待。
7. 到输出目录打开视频和文档，确认结果后再处理更多内容。

## 选哪个入口

| 你现在有什么 | 从哪里开始 |
| --- | --- |
| 平台账号，想查看自己的课程 | `A` → 平台列表 → 对应产品入口 |
| 具体课程网页链接 | 支持课程链接的平台入口或首页输入框 |
| MP4、MP3、M3U8 媒体地址 | [媒体链接指南](Platform-media_links.md) |
| 已有课程 HTML 或特定播放地址 | [转换工具说明](Board-and-Conversion.md) |
| 没找到专用平台入口 | 了解[万能下载模式](Universal-Mode.md)的适用条件 |

## 成功后应该看到什么

课程、章节或资源文件出现在你选择的输出目录中。文件命名和目录深度因平台而异；本文示例不要求实际输出与示意完全相同。

如果列表为空，先检查[账号与登录](Login-and-Accounts.md)。如果任务已开始但缺文件，按[排错指南](Troubleshooting.md)核对。
