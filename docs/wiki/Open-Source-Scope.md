# 哪些内容开源，哪些属于官方客户端


## 本仓库公开的内容

| 内容 | 状态 |
| --- | --- |
| 产品介绍、安装和操作指南 | 公开 |
| 平台名称、分类与公开教程地址 | 公开 |
| 虚构课程、通用数据类型、目录展示 | 公开，可运行 |
| 示例组件接口 | 公开，仅抽象约定 |
| 测试、公开文件检查和文档贡献流程 | 公开 |
| 官方客户端核心引擎及平台适配实现 | 不在此仓库提供 |
| 官方账号系统、服务端与内部协议 | 不在此仓库提供 |

## 三个常见误解

**源码包不是完整产品。** 下载或克隆本仓库可以运行离线示例，但无法获得官方客户端下载能力。

**Release 二进制不自动获得 MIT 授权。** 本仓库 MIT License 适用于公开代码和文档；单独分发的官方客户端及其第三方依赖按各自条款提供。

**示例接口不是插件 SDK。** 它们是从零编写的通用设计示例，不承诺与官方内部接口兼容。

## 可以如何使用

在 MIT 条款下阅读、修改和再分发公开骨架及文档。使用学无止名称或提及支持平台时，避免制造官方背书或合作关系的误解。课程内容的许可仍由课程权利人决定。
