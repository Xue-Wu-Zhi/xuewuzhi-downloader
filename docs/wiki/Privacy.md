# 隐私、内容权限与反馈


## 使用课程内容

只处理自己有权访问并获准保存的课程。购买、报名、课程有效期与资料开放范围由课程平台控制。本仓库和软件许可不改变课程内容的版权。

## 公开反馈前移除什么

| 信息 | 建议处理 |
| --- | --- |
| 手机号、邮箱、真实姓名 | 删除或遮挡 |
| Cookie、Token、验证码、登录二维码 | 不提交 |
| 完整课程地址 | 检查并移除鉴权参数，必要时只写平台和入口类型 |
| 订单、个人课程列表 | 仅保留必要的脱敏信息 |
| 课程视频、音频、讲义 | 不上传到公开 Issue 或仓库 |
| 本地账号缓存与浏览器资料 | 不提供 |

## 哪些信息有助于定位问题

客户端版本、Windows 版本、平台名称、出错步骤、经过脱敏的错误提示，以及原平台是否可以打开同一课程。通常不需要账号秘密就能开始分析问题。

## 关于开源骨架

骨架只展示虚构课程并读取随仓库提供的公开元数据，不需要登录、配置凭证或下载课程。这个说明针对公开示例，不替代官方客户端的隐私说明与实际使用条款。

涉及隐私或安全漏洞时，按 [SECURITY](../../SECURITY.md) 通过官网入口联系维护者。
