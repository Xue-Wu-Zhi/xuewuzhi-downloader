# 课件、讲义与附件


## 课件从哪里来

课件来自课程平台向当前账号开放的资料。PDF、PPT、文档、音频和其他附件是否出现，取决于平台和课程，并非每个课节都同时带有讲义。

## 操作流程

![选择课程讲义、PDF、PPT和文档附件的操作图解](../../assets/guides/courseware.png)

*通用操作示意，使用虚构数据；不是客户端截图，具体界面以当前版本为准。* [查看大图](../../assets/guides/courseware.png)

1. 在原平台查看对应课节是否有资料或附件。
2. 在下载器中选择正确课程、期次及章节。
3. 如果界面提供资源类型选择，勾选需要的资料类型；有“仅资料”模式时可按需使用。
4. 完成后检查课程目录和资料子目录，核对文件扩展名和内容。

## 常见现象

| 现象 | 建议检查 |
| --- | --- |
| 有视频，没有课件 | 原平台是否提供课件；是否漏选资料类型 |
| 资料比章节少 | 并非每一章都有独立附件 |
| 文件名相似 | 是否来自不同课节、不同版本或不同附件 |
| 文档打不开 | 文件是否完整，是否仍在写入，阅读软件是否支持 |
| 原平台是在线阅读器 | 页面内容不一定有独立可下载附件 |
| 附件链接失效 | 重新登录并重新加载课程资源 |

## 整理与反馈

建议先核对完整性，再移动或重命名文件。反馈缺附件时提供平台、客户端版本、所选资料类型及原平台是否可见；不要上传整套课件或包含个人标识的下载链接。
