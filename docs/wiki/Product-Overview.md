# 学无止下载器是什么？功能、平台与开源范围

**学无止下载器（Xuewuzhi Downloader）是面向 Windows 的网课视频下载与课件整理工具。** 官方客户端用于保存获准访问的课程视频、已开放回放、音频及课程附件，并处理支持格式的板书和三分屏内容。下载结果取决于平台、账号权限与课程资源。

## 支持哪些平台的视频下载？

平台涵盖高校课程、网课学习、会议与企业培训。请查阅[完整平台名称表](Platforms.md)，按实际上课的产品入口选择。同一品牌的不同客户端或产品线可能有各自教程。

## 是否完整开源、免费使用？

公开骨架和文档按 MIT 许可提供，完整官方客户端的核心实现没有包含在仓库中。客户端试用、会员及服务规则以官方当前说明为准，MIT 许可不代表客户端下载服务永久免费。[开源范围](Open-Source-Scope.md)

## 如何开始？

获取官方客户端 → 选择平台或课程链接 → 登录课程账号 → 选择章节与资源 → 下载并等待处理 → 核对结果。[查看操作图解](Illustrated-Guide.md)
