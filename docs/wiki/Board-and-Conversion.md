# 板书、三分屏与课程转换


## 为什么下载完还要处理

部分课程将教师视频、演示文稿、板书轨迹和音频分别提供。要得到可本地播放的结果，可能需要继续合成或转换，因此网络下载完成不等于整个任务完成。

## 转换前检查

保留 HTML 和它依赖的资源文件的原有关系。确认输出目录可写、空间充足；在线资源必须仍可访问。如果客户端提示缺少浏览器或处理工具，按具体提示修复环境。

## 转换过程中

处理可能持续较长时间，取决于课程时长、画面内容、计算机性能和资源访问情况。查看是否仍有进度或输出变化，不要仅根据“网络速度为零”判断已经卡死。

## 结果不一致时

对照原平台同一时间点，检查背景、板书、音频和画面布局。记录发生时间、任务类型、版本以及具体差异；反馈截图前移除账号和课程隐私。

若缺少依赖资源、原链接已经过期或输入格式不受支持，转换无法凭空还原缺失内容。先排除这些情况，再按[排错指南](Troubleshooting.md)反馈。
